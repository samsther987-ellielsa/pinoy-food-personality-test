# 원본 사진 촬영 계획

**작성일:** 2026-08-04
**목적:** 스톡 사진을 직접 촬영한 원본 사진으로 교체해 E-E-A-T의 "Experience"를 확보한다.
**배경:** Search Console에서 실제 콘텐츠 페이지 17개가 `크롤링됨 - 현재 색인이 생성되지 않음` 상태.
페이지 텍스트는 98% 고유한 것으로 측정됐으므로 중복 문제가 아니며, 남은 차별화 레버는 원본 이미지다.

---

## 0. 대전제 — 인터넷에서 "찾은" 사진은 효과가 없다

무료든 유료든, 이미 인터넷에 존재하는 사진은 구글이 역이미지 검색으로 즉시 식별한다.
현재 `images/dishes/*.jpg` 16장이 전부 그 상태다 (Pexels 스톡 11장 + Wikimedia Commons 5장).

**가치가 생기는 조건은 단 하나 — 세상에 없던 사진일 것.**
폰카로 충분하다. 화질이 아니라 "존재하지 않던 이미지"라는 사실 자체가 신호다.

스톡을 더 찾아 교체하는 작업은 **하지 말 것.** 시간만 쓰고 효과는 0이다.

## Tier 1 — 아도보 조리 과정 6장 (최우선)

**왜 아도보부터인가**
- 필리핀 요리 중 검색량 1위
- 재료가 전부 한국 일반 마트에서 구매 가능 — 특수 재료 0개
- `recipes/adobo.html` 페이지가 이미 완성되어 있어 사진만 끼우면 됨

**장보기 목록** (`recipes/adobo.html` 재료 그대로)

- [ ] 닭다리살·북채 1kg
- [ ] 간장 1/2컵
- [ ] 식초 1/2컵 (백식초 또는 사탕수수식초)
- [ ] 마늘 1통 (으깬 것)
- [ ] 건월계수잎 3장
- [ ] 통후추 1작은술
- [ ] 물 1컵
- [ ] 식용유 2큰술
- [ ] 흑설탕 1큰술 (선택)

**촬영 목록** — 페이지의 실제 5단계에 1:1 매핑

| # | 사진 | 삽입 위치 | 메모 |
|---|---|---|---|
| 1 | 재료를 전부 늘어놓은 컷 | Ingredients 섹션 상단 | 위에서 내려찍기 |
| 2 | 간장·으깬 마늘에 재워둔 닭 | Step 1 | 볼에 담긴 상태 |
| 3 | 팬에서 겉면을 굽는 중, 갈색이 나는 상태 | Step 2 | 마리네이드는 따로 빼둔 게 보이면 더 좋음 |
| 4 | **식초·물·월계수잎·통후추를 넣고 끓는 냄비, 뚜껑 열린 상태** | Step 3 | **가장 중요. 아래 설명 참조** |
| 5 | 소스가 졸아 윤기 나는 팬 안 클로즈업 | Step 5 | |
| 6 | 밥과 함께 담은 완성컷 | **히어로 사진 교체** | 현재 스톡 `adobo.jpg` 대체 |

**4번이 왜 중요한가**

레시피 Step 3에 이렇게 써두었다:

> Let it come to a boil WITHOUT stirring, so the raw sharpness of the vinegar cooks off.

젓지 않고 끓이는 그 순간의 사진은 **실제로 만들어본 사람만 찍을 수 있는 컷**이다.
스톡 사이트에 이런 사진은 없다. E-E-A-T에서 말하는 Experience가 정확히 이것이다.

## Tier 2 — 참포라도 조리 과정 6장

두 번째로 쉽다. 재료 전부 마트에서 구매 가능하고 조리 시간이 짧다.

**장보기 목록**

- [ ] 찹쌀 1컵
- [ ] 물 4컵
- [ ] 코코아파우더 1/4컵 (무가당) — 타블레아 구할 수 있으면 4개
- [ ] 설탕 1/2컵
- [ ] 소금 약간
- [ ] 연유

**촬영 목록**

| # | 사진 | 삽입 위치 |
|---|---|---|
| 1 | 재료 전체 | Ingredients 섹션 |
| 2 | 씻은 찹쌀 + 끓는 물 | Step 1 |
| 3 | 저어가며 끓이는 중, 걸쭉해지기 시작한 상태 | Step 2 |
| 4 | 코코아를 넣어 초콜릿색으로 변하는 순간 | Step 3 |
| 5 | 걸쭉하고 윤기 나는 완성 직전 | Step 4 |
| 6 | 그릇에 담고 연유를 부은 완성컷 | **히어로 교체** |

여력이 되면 튀긴 뚜요(말린 생선)를 곁들인 컷을 하나 더. Step 5에 그 조합을 언급해 두었다.

## Tier 3 — About 페이지용 1~2장

**얼굴은 안 나와도 된다.** 필요한 건 인물 사진이 아니라 "실제로 이걸 하는 사람"이라는 증거다.

- [ ] 요리하는 손 (재료 다듬는 중, 냄비 젓는 중 등)
- [ ] 본인 주방 또는 도마 위 재료

`about.html`에 이미 이렇게 써두었다:

> 전문 셰프도 음식사학자도 아닌, 직접 요리하고 자료를 찾아보는 애호가

이 문장 옆에 실제 본인 주방 사진이 붙으면 그 진술이 **검증 가능한 주장**이 된다.
지금은 텍스트 주장일 뿐이다.

## Tier 4 — 나머지 레시피 히어로 (여력 될 때)

우선순위 순서:

1. [ ] 판싯 칸톤 — 면은 아시안마트/온라인, 나머지는 일반 마트
2. [ ] 룸피아 — 룸피아 래퍼는 스프링롤 피로 대체 가능
3. [ ] 시니강 — 삼파록(타마린드) 믹스 온라인 구매 필요

**카레카레는 제외한다.** 우족·아나토·바궁이 전부 필요해 한국에서 난이도가 급격히 올라간다.
투입 시간 대비 효과가 나쁘다.

## 촬영 규격

- **해상도** — 최소 가로 1500px. 최종적으로 1000×667로 리사이즈하지만 원본은 따로 보관할 것
- **EXIF를 지우지 말 것** — 촬영 날짜·기기 정보가 남아 있는 편이 원본임을 뒷받침한다.
  편집 앱이 자동으로 지우는 경우가 많으니 주의. 보정을 하더라도 메타데이터는 유지
- **자연광, 위에서 내려찍기.** 필터·과한 보정 금지 — 스톡처럼 보이는 순간 차별점이 사라진다
- **접시가 완벽할 필요 없다.** 약간 지저분한 진짜 주방이 오히려 신뢰를 준다.
  스타일링된 사진일수록 스톡과 구별이 안 된다
- **가로 3:2 비율** 권장 (기존 이미지가 전부 1000×667 = 3:2)

## 전달 방법

폴더 하나에 몰아넣고 경로만 알려주면 된다. 파일명은 아무렇게나 해도 되지만,
**어느 단계 사진인지 구분할 수 있게** 순서대로 번호를 붙이거나 메모를 남길 것.

예시:
```
~/Desktop/adobo-photos/
    1-ingredients.jpg
    2-marinade.jpg
    3-browning.jpg
    4-boiling-no-stir.jpg
    5-reduced.jpg
    6-plated.jpg
```

## 사진을 받은 뒤 내가 할 작업

1. 1000×667 리사이즈 + 최적화, `images/recipes/<dish>/step-N.jpg` 구조로 정리
2. 레시피 페이지 각 단계에 삽입 + 서술적 alt 텍스트 작성
3. **Recipe 스키마의 `HowToStep`에 `image` 필드 추가**
   현재 스텝별 이미지가 없다. 이게 붙으면 구글 레시피 리치 결과 자격이 올라간다.
   Search Console 사이드바에 `개선사항 → 레시피` 리포트가 이미 잡히고 있으므로 반응 확인 가능
4. 히어로 사진 교체 + 해당 페이지 `og:image` 갱신
5. `about.html`의 Photo Credits에서 교체된 스톡 사진 출처 정리
   (Wikimedia CC BY-SA 사진을 교체하면 해당 저작자 표시 항목도 제거)
6. `sitemap.xml`의 lastmod 갱신 + Playwright 테스트 추가
7. Search Console에서 해당 URL 색인 재요청

## 범위 밖 — 사진으로 해결되지 않는 것

색인 거부된 블로그 4개는 **사진과 무관한 문제**다.

| 색인 거부 | 색인됨 |
|---|---|
| `mbti-food-personality-connection` | `history-of-sinigang` |
| `mbti-types-and-eating-habits` | `adobo-regional-variations` |
| `filipino-food-culture-guide` | `filipino-street-food-guide` |
| `global-rise-of-filipino-food` | `how-to-host-kamayan`, `filipino-food-superstitions` |

왼쪽은 일반론·개괄, 오른쪽은 구체적이고 특정 질문에 답하는 글이다.
가장 짧은 글(`kpop-filipino-food-culture`, 1,111단어)은 오히려 색인됐으므로 **길이가 아니라 구체성**의 문제다.

이 4개는 주제를 구체화하는 별개 작업이며, 사진 없이 진행 가능하다.

## 현실적인 기대치

- 이 작업은 **레시피 페이지에 강한 레버**이고, 결과 페이지 16개에는 직접적 효과가 없다
- 사진을 넣는다고 색인이 보장되지는 않는다. 사이트 권위는 시간과 유입이 필요하다
- 다만 지금 시점에서 **코드로 할 수 있는 건 이미 다 했다.**
  남은 것 중 통제 가능한 레버는 원본 사진과 콘텐츠 구체화 두 가지뿐이다
