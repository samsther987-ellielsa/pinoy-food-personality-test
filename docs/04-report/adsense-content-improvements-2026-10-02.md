# 애드센스 저가치 콘텐츠 대응 실행 결과

2026년 10월 2일, [개선 계획](../adsense-approval-plan-2026-10-01.md)의 콘텐츠·탐색·추적 관련 수정을 실행하고 [운영 사이트](https://pinoyfoodtest.com)에 배포했다. 실제 조리 기록과 원본 사진은 제공받지 않았으므로 조사 기반 콘텐츠라고 명시했다. 애드센스 재심사 요청이나 승인 완료를 뜻하지 않는다.

음식 소개를 앞세웠던 초기 배치는 사용자의 테스트 사이트 의도와 맞지 않아 바로 수정했다. 홈 메타데이터와 About 소개도 테스트 중심으로 맞췄다.

## 실행한 개선

| 레시피 6개 | 영어·타갈로그 재료와 단계, 예상 시간, 익힘 확인, 보관·재가열 안내, 대체 재료의 조건과 출처를 보완했다. 아도보는 재우기 30분을 포함한 총 90분으로 정리했다. 빠져 있던 판싯과 카레카레의 기름·물도 포함했다. |

## 검증 결과

- Chromium 자동 검사 19개 통과. 모바일 360px, 영어·타갈로그 전환, 결과 16개, 사진 로드, 레시피 재료·단계와 JSON-LD 일치, 인쇄, 동의 전 GA 미로드·동의 저장·철회, 문의 label·유효성, 영구 이동을 검사했다.
- 저장소 HTML 50개와 JSON-LD 93개 구문 확인. 정적 내부 링크·이미지 경로가 존재하며, `git diff --check`도 통과했다.
- 홈 방향 수정 후 자동 검사 19개를 다시 통과했다. 360px 첫 화면에 테스트 시작 버튼이 완전히 보이는지, 테스트 → 진행 방식 → 결과 → 보조 콘텐츠 순서인지 검사했다. 390px 브라우저 화면에서도 확인했다. 운영 아도보의 타갈로그·다크 모드·재료 목록·출처·분석 off 상태도 확인했다.
- 배포 후 저장소 HTML 50개에 대응하는 공개 경로 모두 리다이렉트 후 HTTP 200. 없는 경로는 404. 운영 사이트맵은 22 URL이고 `ads.txt`의 게시자 식별자가 유지된다.
- 문의 메시지를 실제로 전송하지 않았다. 자동 검사는 분석 스크립트를 가짜 응답으로 처리하므로 시험용 GA 데이터도 전송하지 않는다.

재현 명령은 `npm test -- --reporter=line --workers=3`이다. Playwright Chromium이 설치되어 있어야 한다. 이번 환경에서는 임시 경로에 설치한 브라우저를 사용했다:

```sh
PLAYWRIGHT_BROWSERS_PATH=/private/tmp/pinoy-playwright npm test -- --reporter=line --workers=3
```

## 사용자 자료·계정 확인이 필요한 후속 작업

1. 실제로 만든 음식의 재료·과정·완성 사진과 시간·맛·실패 메모가 있으면 조사 기반 가이드에 직접 경험을 추가한다. 현재 이미지를 직접 촬영한 것으로 설명하지 않는다.
2. 운영자가 본인의 실제 소개와 문의 수신을 확인한다. 제공되지 않은 체험담은 About에 넣지 않았다.
3. AdSense 대시보드에서 최신 거절 안내와 재신청 가능 여부를 확인한 뒤 재심사를 요청한다. 이 작업에서는 재심사 요청을 제출하지 않았다.
4. 광고를 다시 켜기 전에 광고 대상·계정의 Auto ads·필요한 인증 CMP와 개인정보 안내를 맞춘다. 현재의 선택 도구는 선택적 GA4 제어이며 Google 인증 광고 CMP라고 주장하지 않는다.

코드와 공개 콘텐츠 개선은 완료했다. 이 보고서는 실제 검색 색인 완료나 애드센스 승인을 증명하지 않는다.
